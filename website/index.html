Safety model

Designed so a mistake is recoverable

PrivacyGuard will not disable core Windows services. Changes go through one service layer, with confirmation and a backup first.

1

Confirm

A dialog lists old → new values and side effects before any write.

2

Backup

A restore point is saved under %LocalAppData%\PrivacyGuard\ before the change.

3

Apply

Only allowlisted registry keys and two optional services (DiagTrack, WAP Push) can be changed.

4

Revert

History can undo a single setting or replay a full restore point.

FAQ

Straight answers before you install.

Can I get this on Google Play?

No. Google Play is for Android. PrivacyGuard is a Windows desktop app. Download it from this website, or later from the Microsoft Store — never from an Android store.

Will it break Windows Update or Security?

Recommended Privacy is built to keep Update and Security healthy. Maximum Privacy is more aggressive and may hide optional experiences such as Copilot until you sign out. You can restore defaults from the app at any time.

Does it need administrator rights?

You can inspect everything as a standard user. Changing machine policy, DiagTrack, Copilot, or Cortana requires Restart as admin, which triggers Windows UAC. Nothing elevates silently.

Where is my data stored?

On your PC only. Logs and a local SQLite database live under %LocalAppData%\PrivacyGuard\. PrivacyGuard does not upload your settings or history.
