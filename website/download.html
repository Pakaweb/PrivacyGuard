Before you install

Requirements

  • Windows 10 1809+ or Windows 11 x64 desktop. Mac and Linux cannot run the app.
  • Administrator only when needed. Restart as admin is required for machine policy or services. Nothing elevates silently.
  • No Microsoft account required. History and restore points stay on this PC under %LocalAppData%\PrivacyGuard\.
Download only from trusted sources

Prefer this website or, later, the Microsoft Store — not random mirrors. On a work PC, review the confirmation dialog before applying changes.
