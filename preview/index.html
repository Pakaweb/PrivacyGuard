Settings

App preferences only. Windows privacy settings live on the Dashboard and Profiles pages.

Appearance

Theme

Follow Windows, or force a light or dark theme.

Language

Changes the entire PrivacyGuard interface. Dates and numbers follow this language too.

Startup & safety

Start with Windows

Adds or removes a current-user Run key. Does not require administrator rights.

Confirm before applying changes

Confirmation dialogs are always shown. This switch is locked on for safety.

Record change history

Write every setting mutation to the local SQLite database.

Show in the notification area

Keeps a PrivacyGuard icon in the system tray while the app is running.

Close to tray

The close button hides the window. Use Exit on the tray menu to quit.

Watch for Windows resetting settings

On startup and every 10 minutes, compare Windows privacy settings to the last PrivacyGuard apply.
